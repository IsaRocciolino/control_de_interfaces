
El robot debe tener un peso considerable para generar mas estabilidad frente a los choques.
El peso debe estar principalmente entre las dos ruedas grandes para generar un centro de gravedad y una mayor fuerza de traccion en tales ruedas. 
El peso no puede estar cerca de la rueda chica. 
Para el peso adicional vamos a utilizar:
Plomos de pesca 
Planchuelas de hierro
Tuercas grandes de acero.
para la estructura vamos a utilizar aluminio e impresión 3D.
En la parte de adelante va a llevar un paragolpes de aluminio para proteger la base de plastico absorviendo la enería del golpe.
En la parte delantera vamos a colocar una rampa.
